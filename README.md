# จองห้องประชุม Happy CU

เว็บจองห้องประชุมสำหรับคนในบริษัท ใช้ได้ทั้งมือถือและคอมพิวเตอร์

- หน้าเว็บอยู่บน **GitHub Pages** (ฟรี)
- ข้อมูลการจองเก็บใน **Google Sheets** ผ่าน Google Apps Script (ฟรี) เปิดชีตดูการจองทั้งหมดได้เลย
- ถ้ายังไม่ได้เชื่อม Google Sheets เว็บจะอยู่ใน "โหมดทดลอง" เก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนั้นเครื่องเดียว

## ไฟล์ในโปรเจกต์

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `index.html`, `styles.css`, `script.js` | หน้าเว็บ |
| `config.js` | ใส่ลิงก์ของ Google Apps Script |
| `apps-script/Code.gs` | โค้ดหลังบ้าน วางใน Google Apps Script |

## ขั้นที่ 1: สร้างที่เก็บข้อมูลใน Google Sheets

1. เข้า [sheets.new](https://sheets.new) สร้างชีตใหม่ ตั้งชื่อเช่น `Happy Room Bookings`
2. ไปที่เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมทิ้ง แล้ววางโค้ดทั้งหมดจากไฟล์ `apps-script/Code.gs` กดบันทึก
4. กดไอคอนรูปเฟือง **การตั้งค่าโปรเจกต์** ตั้ง **เขตเวลา** เป็น `(GMT+07:00) Bangkok`
5. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
6. กดทำให้ใช้งานได้ แล้วกดอนุญาตสิทธิ์ให้บัญชี Google ของคุณ
7. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

ไม่ต้องสร้างแท็บในชีตเอง ระบบจะสร้างแท็บ `Bookings` ให้ตอนมีคนจองครั้งแรก

## ขั้นที่ 2: เชื่อมหน้าเว็บกับชีต

เปิดไฟล์ `config.js` แล้ววาง URL ที่คัดลอกมา

```js
window.HAPPY_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
};
```

## ขั้นที่ 3: เอาขึ้น GitHub Pages

1. สร้าง repository ใหม่ใน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. ไปที่ **Settings → Pages**
3. ตรง Source เลือก **Deploy from a branch** เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอสักครู่ จะได้ลิงก์ประมาณ `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/` ส่งลิงก์นี้ให้คนในบริษัทได้เลย

## เมื่อแก้โค้ดใน Apps Script

ทุกครั้งที่แก้ `Code.gs` ต้องไปที่ **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** ไม่อย่างนั้นเว็บจะยังใช้โค้ดเก่า (URL เดิมใช้ต่อได้)

## กติกาการจอง

- จองได้วันละ 08:00–17:00 น. ครั้งละไม่เกิน 4 ชั่วโมง ล่วงหน้าได้ 60 วัน (กด "ดูปฏิทิน" เพื่อเลือกวันที่เกิน 7 วัน)
- ระบบกันไม่ให้จองเวลาชนกัน แม้สองคนกดพร้อมกัน
- ตอนยกเลิกต้องใส่เบอร์หรืออีเมลที่ใช้ตอนจอง ถ้าจองจากเครื่องเดิม ระบบจำไว้ให้ ไม่ต้องพิมพ์ใหม่
- เบอร์และอีเมลของผู้จองจะเห็นได้เฉพาะในชีต ไม่แสดงบนหน้าเว็บ
- ถ้าต้องการลบหรือแก้การจองแทนคนอื่น ให้แก้ในชีตได้เลย (คอลัมน์ `status` ใส่ `cancelled` = ยกเลิก)
